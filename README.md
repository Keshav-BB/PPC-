# People Point Consultants — Premium Website

> **Turn Ideas Into Running Businesses.**  
> *Build Your Business. We'll Build the Systems Behind It.*

Comprehensive digital platform for **People Point Consultants**, providing end-to-end business enablement across Business Setup, HR, Payroll, Compliance, Technology, Operations, and Growth.

---

## 🚀 Key Features

- **Complete 19-Section Homepage**: Outcome-focused messaging, interactive business journey selector, 7 core solution pillars, 30-day turnkey roadmap, core leadership team, case studies, and testimonials.
- **7 Dedicated Solution Pages**:
  - [Business Setup & Registration](/solutions/business-setup)
  - [HR & People Operations](/solutions/hr-people)
  - [Payroll & Compliance](/solutions/payroll-compliance)
  - [Technology Services](/solutions/technology)
  - [Accounts & Backend Support](/solutions/accounts-backend)
  - [Business Process & Operations](/solutions/process-operations)
  - [Digital Marketing & Growth](/solutions/digital-marketing)
- **Interactive Conversion Architecture**:
  - **Business Readiness Assessment (`/assessment`)**: 12-question diagnostic test scoring across 6 pillars with real-time gap analysis.
  - **Custom Solution Builder (`/solution-builder`)**: Interactive scope and budget configurator.
  - **Multi-Step Consultation Booking Modal**: High-intent lead capture with calendar scheduling simulation.
  - **Contextual WhatsApp Routing**: Dynamic page-aware prefilled messaging.
  - **Executive CRM Leads Pipeline (`/admin/leads`)**: Visual pipeline tracking (*New Lead → Qualified → Consultation Scheduled → Proposal Sent → Won*) with search, filters, and CSV export.
- **Packages & Engagement (`/packages`)**: Detailed scope breakdown of *Business Launch 360°*, *HR Foundation*, *Managed People Operations*, etc.
- **How We Work (`/how-we-work`)**: 6-stage execution framework (Understand → Assess → Design → Execute → Measure → Support).

## 💻 Getting Started

### Prerequisites

- Node.js 18.17+ or 20+
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/Keshav-BB/PPC-.git
cd PPC-

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Building for Production

```bash
npm run build
npm run start
```
